# ol1dog (올리독) — 컨셉 리디자인 (포트폴리오용)

애견 커스텀 자수 산책용품 브랜드 **컬러 유어 올리독** (smartstore.naver.com/ododog)의 가상 브랜드 사이트.
공식 사이트 아님.

- 스택: Vite + 바닐라 JS/CSS
- 실행: `npm install && npm run dev`
- 데이터: `src/data.js` — 2026-10-29 네이버 검색 쇼핑 블록에서 수집한 실제 상품명·가격·별점·리뷰수
  (스마트스토어 본체는 비로그인 접근 시 로그인 페이지로 리다이렉트돼서 못 긁음)
- 이미지: `public/img/` — 네이버 쇼핑 썸네일 640px

## 디자인 컨셉 (v2)
핸드메이드 자수·미싱. 린넨 바탕 + 박음질(dashed stitch) + 자수틀(hoop) + 직조 라벨 + 실패 + 가격 택 + 마스킹테이프 폴라로이드.
- 컬러: 린넨/오트/버터/로즈/세이지 소프트톤, 포인트 클레이 `#b9735a`
- 폰트: Gaegu(크레용 손글씨, `#crayon` SVG 필터) · Nanum Pen Script(손메모) · Caveat(`ol1dog` 워드마크 — 1이 숫자로 읽히게) · Gowun Dodum(본문)
- 브랜드 표기는 **ol1dog** (알파벳 I 아님, 숫자 1)

## 섹션
Hero(자수틀 + 바늘 + 박음질 실) → 그로그랭 리본 마키 → **자수 커스터마이저**(아이템/이름/아이콘/웨빙 원단/실패 → 새틴 스티치 프리뷰) →
컬렉션(카테고리 필터, 코튼 라인 먼저) → 만드는 과정 4단계 + 벤토 → 직조 라벨 숫자 → 폴라로이드 갤러리 → 푸터
